## What M1 adds on top of M0

- **Frontend surface** (`lig-parse-solid`): typed state lattice, `<For>` lists with
  unkeyed diff, delegated events with payload slots, component uses + slots,
  dynamic styles with prev-diff slots, spreads, and the `model!`/`native!`
  escape hatches (D-6) — all lowered to the canonical View IR and pinned by
  four new behavior fixtures (`component-use`, `destructure-props`,
  `dynamic-style`, `event-object`) alongside the original twelve.
- **Admission tiers v1** (`lig-admission`): the Deny / Lint / Allow ladder as a
  query over the IR; profile-aware tiering (`Layout` vs `Web`); every rule row
  links its allow/deny fixtures; lowering-time diagnostics participate in the
  same report.
- **Source maps** (`lig-sourcemap`): chained standard-VLQ maps — source→IR and
  IR→Rust legs chained into one map, IR node names in `names[]` (ADR-011);
  verified before emission (NFR-6) via `lig build`.
- **The `lig` CLI** (§12.1): `check` (exit 0 clean / 1 denied / 2 internal,
  `--deny-warn`, `--profile taffy|web`), `build` (fail-closed BR-1, zero output
  on any Deny; emits `<unit>.rs`, `ir/<unit>.json`, `maps/<unit>.map.json`,
  `manifest.toml` atomically), `explain <code>` (generated catalog, D-7),
  `resolve <map> <line> <col>`, `inspect <file>`, `fixtures verify|admission`.
  Locked by `crates/lig-cli/tests/cli.rs` (4 integration tests).
- **Project rename**: the project is now **Ligature** — workspace `ligature`,
  all crates `lig-*`, error codes `LIG-*` (docs/errors regenerated, registry
  reproducible via `xtask errors-gen`), domain `ligature.dev`, binary `lig`,
  env protocol vars `LIG_TIP_*` / `LIG_PATCH_DYLIB`. Zero references to the
  former name remain (enforced by grep across the tree).
